How s402 works

Three steps. No API keys. No signup. No credit card.

1

Agent requests data

Your AI agent calls s402_fetch(url) like a normal API request.

2

Server demands payment

The API returns 402 with price, network, and accepted payment schemes.

3

Agent pays & gets data

@sweefi/mcp signs a Sui transaction, retries the request, and returns 200 + receipt.

Try it in 30 seconds

Add @sweefi/mcp to Claude Code and ask it to fetch a paid endpoint.

1

Add @sweefi/mcp to your Claude Code config

Add this to ~/.claude/settings.json under mcpServers: 

{
  "mcpServers": {
    "sweefi": {
      "command": "npx",
      "args": ["@sweefi/mcp"],
      "env": {
        "SUI_PRIVATE_KEY": "suiprivkey1...",
        "SUI_NETWORK": "testnet"
      }
    }
  }
}
2

Get testnet SUI

Generate a keypair and fund it from the faucet: 

# Generate a new keypair
sui keytool generate ed25519

# Fund it on testnet
sui client faucet --address <your-address> --network testnet
3

Ask your agent to fetch a paid endpoint

In Claude Code, just ask: 

# In Claude Code, type:
"Fetch me a joke from https://demo.s402-protocol.org/api/joke"

# @sweefi/mcp handles the 402 negotiation automatically.
# Your agent pays, gets the joke, and shows you the receipt.

The s402 protocol

A chain-agnostic HTTP 402 wire format. Five payment schemes. Zero runtime dependencies. Wire-compatible with x402 (Coinbase).

Exact

One-shot payment. Sign a transaction, send it in the header, get your data. Simplest scheme.

Prepaid

Deposit upfront, then make thousands of calls. 500x cheaper per-call for high-frequency access.

Stream

Per-second billing. Pay for exactly what you use, in real time. Perfect for long-running queries.

Escrow

Time-locked vault with dispute resolution. Buyer protection for high-value API calls.

Unlock

Pay-to-decrypt. Content is encrypted on the wire, key is released after settlement.
